# Русификатор Total War: Arena (Revival)

Неофициальный фанатский перевод клиента **Total War: Arena** (сборка Revival) на русский язык.

> **Статус:** переведено около 17 800 строк: интерфейс, настройки, подсказки, способности, характеристики, названия отрядов, снаряжения, достижения, обучение, ошибки. Остальное пока на английском (длинные описания отрядов, биографии полководцев, описания карт, реплики быстрого чата, часть названий снаряжения). Помощь приветствуется: [CONTRIBUTING.md](CONTRIBUTING.md).

В репозитории **нет файлов игры**. Здесь таблицы перевода и программа, которая вставляет их в ваши собственные файлы игры.

## Установка (3 клика)

1. Скачайте **`TWA-Russian.exe`** на странице [Releases](https://github.com/tverzar/twa-ru-localization/releases/latest).
2. **Закройте игру и лаунчер**, запустите `TWA-Russian.exe`. Программа сама найдёт папку игры (если не нашла, нажмите «Обзор…» и выберите папку с `Arena.exe`).
3. Нажмите **«Установить русификатор»**. Дальше можно жать **«Запустить игру»**.

Программа сама:
- делает **бэкап** оригинальных файлов (в `<игра>\data\backup_ru`);
- ставит перевод;
- **возвращает английский** кнопкой «Вернуть английский»;
- замечает, что игра **обновилась** или файлы изменила другая программа, и не затирает их старыми копиями: сохраняет новые оригиналы и ставит перевод заново.

> Windows может показать предупреждение SmartScreen («неизвестный издатель»): программа не подписана цифровой подписью. Нажмите «Подробнее → Выполнить в любом случае». Если не доверяете exe, соберите его сами или запустите из исходников (см. ниже): код открыт, лежит в `tools/`.

### Без exe (нужен Python 3.8+)

Скачайте репозиторий (*Code → Download ZIP*), распакуйте и запустите **`Запустить русификатор.bat`**. Откроется то же окно.

### Командная строка (для продвинутых)

```bash
python tools/twa_ru.py apply   --game "D:\Total War Arena"   # установить / обновить
python tools/twa_ru.py restore --game "D:\Total War Arena"   # вернуть английский
python tools/twa_ru.py report  --game "D:\Total War Arena" --csv report.csv   # что не влезло
```

## Если что-то пошло не так

- **Игра падает на первой картинке:** нажмите «Вернуть английский», убедитесь, что игра запускается, и напишите в [Issues](https://github.com/tverzar/twa-ru-localization/issues) (версия клиента, что в окне программы).
- **Программа пишет «другая сборка клиента»:** проверенная версия клиента имеет `local_en.pack` 116 373 279 байт и `text.pack` 7 663 873 байта. На другой версии перевод не тестировался. Продолжить можно из командной строки с `--force` (на свой риск).
- **«Закройте игру и лаунчер»:** пока запущены `Arena.exe` или `twa-launcher.exe`, файлы менять нельзя.
- **«В паке уже есть кириллица»:** файлы изменены другим русификатором. Через лаунчер проверьте/восстановите файлы игры и повторите.

## Почему часть строк осталась английской

Клиент проверяет размер **каждого файла внутри пака**: если он изменился хоть на байт, игра падает на первой заставке (проверено экспериментами, причина в самом клиенте пока не найдена). Поэтому русский текст должен занимать ровно столько же места, сколько английский. Если перевод длиннее, программа:

1. пробует сократить слова по словарю [`translations/abbreviations.tsv`](translations/abbreviations.tsv) (в несколько этапов, от безобидных синонимов до удаления слов-оценок в названиях снаряжения);
2. если всё равно не влезает, оставляет строку английской;
3. остаток места добивает пробелами.

Если вы найдёте, **где игра проверяет размеры файлов** (и как это обойти), напишите в Issues: тогда перевод можно будет не сокращать.

## Как это устроено

- `translations/ru/<таблица>.tsv`: `ключ<TAB>русский текст` (спецсимволы: `\n`, `\t`, `\`). Ключи совпадают с ключами игровых таблиц локализации.
- `tools/twa_ru.py`: ядро (чтение и запись паков PFH5 с зашифрованным индексом, подстановка строк, подгонка размеров, бэкап).
- `tools/twa_ru_gui.py`: окно-установщик.
- Формат пака и алгоритм шифрования индекса взяты из проекта [RPFM](https://github.com/Frodo45127/rpfm) (MIT).

### Сборка exe самостоятельно

```bash
pip install pyinstaller
python -m PyInstaller --onefile --windowed --name TWA-Russian --add-data "translations;translations" tools/twa_ru_gui.py
```

Готовый файл появится в `dist/`. Контрольная сумма exe из релиза указана в описании релиза.

## Права и благодарности

Total War: Arena принадлежит Creative Assembly / SEGA. Проект не связан ни с ними, ни с проектом Revival; игровые тексты и файлы здесь не распространяются. Подробнее: [NOTICE.md](NOTICE.md).

## English summary

Unofficial Russian localisation for the Total War: Arena *Revival* client. Download `TWA-Russian.exe` from [Releases](https://github.com/tverzar/twa-ru-localization/releases/latest), close the game and launcher, run it and click *«Установить русификатор»* (Install). It finds the game, backs up the original files, installs the translation and can restore the originals (*«Вернуть английский»*). The client crashes if the size of any file inside `local_en.pack` / `text.pack` changes, so translations that do not fit the original size are shortened (`translations/abbreviations.tsv`) or left in English. No game files are included. Contributions welcome: [CONTRIBUTING.md](CONTRIBUTING.md).
