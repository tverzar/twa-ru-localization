# Русификатор Total War: Arena (Revival)

Неофициальный фанатский перевод клиента **Total War: Arena** (сборка Revival, где тексты лежат в `data/local_en.pack` и `data/text.pack`) на русский язык.

> **Статус:** ~13 700 строк из ~25 000 переведено и влезает в игру: интерфейс, настройки, подсказки, способности отрядов и полководцев, характеристики, названия отрядов и снаряжения, достижения, обучение. Остальное пока на английском (длинные описания юнитов, биографии полководцев, описания карт и часть советов). Помощь приветствуется, см. [CONTRIBUTING.md](CONTRIBUTING.md).

В репозитории **нет файлов игры**. Здесь только таблицы перевода и скрипт, который применяет их к вашим собственным паками игры.

## Установка

Нужен [Python 3.8+](https://www.python.org/downloads/) (ничего устанавливать через pip не нужно).

1. **Полностью закройте игру и лаунчер.**
2. Скачайте репозиторий (кнопка *Code → Download ZIP*) и распакуйте.
3. В папке репозитория выполните (путь замените на свой):

```bash
python tools/twa_ru.py apply --game "D:\Total War Arena"
```

Скрипт:
- сохранит оригинальные паки в `<игра>\data\backup_ru\` (один раз; повторные запуски всегда берут оригиналы оттуда);
- подставит русский текст в `data\local_en.pack` и `data\text.pack`;
- напишет, сколько строк переведено и сколько не влезло.

4. Запустите игру как обычно.

### Откат

```bash
python tools/twa_ru.py restore --game "D:\Total War Arena"
```

### Обновление перевода

Скачайте новую версию репозитория и снова выполните `apply`. Заново ничего возвращать не нужно.

## Почему часть строк осталась английской

Клиент проверяет размер **каждого файла внутри пака**: если он изменился хоть на байт, игра падает на первой заставке (проверено экспериментами, причина в самом клиенте пока не найдена). Поэтому русский текст должен занимать ровно столько же места, как английский: если перевод длиннее, скрипт

1. пробует сократить слова по словарю [`translations/abbreviations.tsv`](translations/abbreviations.tsv);
2. если всё равно не влезает, оставляет эту строку английской;
3. остаток места добивает пробелами.

Команда `report` показывает, какие строки не поместились:

```bash
python tools/twa_ru.py report --game "D:\Total War Arena" --csv report.csv
```

Если вы найдёте, **где игра проверяет размеры файлов** (и как это обойти), напишите в Issues: это снимет ограничение и позволит переводить без сокращений.

## Если что-то пошло не так

- Игра падает на первой картинке: выполните `restore`, запустите игру, убедитесь, что без перевода всё работает, и приложите описание в Issues (версия клиента, размеры паков).
- Скрипт пишет «другая сборка клиента»: размеры `local_en.pack` (116 373 279 байт) и `text.pack` (7 663 873 байта) должны совпадать с проверенной сборкой. Опция `--force` отключает проверку на ваш риск.
- «Не могу записать пак»: закройте игру и лаунчер.

## Как это устроено

- `translations/ru/<таблица>.tsv`: `ключ<TAB>русский текст` (спецсимволы: `\n`, `\t`, `\\`). Ключи совпадают с ключами игровых таблиц локализации.
- `tools/twa_ru.py`: чтение и запись паков PFH5 (версия Arena с зашифрованным индексом), подстановка строк, подгонка размеров, отчёты.
- Алгоритм шифрования индекса и формат пака взяты из проекта [RPFM](https://github.com/Frodo45127/rpfm) (MIT).

## Права и благодарности

Total War: Arena принадлежит Creative Assembly / SEGA. Проект не связан ни с ними, ни с проектом Revival; игровые тексты и файлы здесь не распространяются. Подробнее: [NOTICE.md](NOTICE.md).

## English summary

Unofficial Russian localisation for the Total War: Arena *Revival* client. Run `python tools/twa_ru.py apply --game "<game dir>"` with the game closed; `restore` reverts. The client crashes if the size of any file inside `local_en.pack` / `text.pack` changes, so translations that do not fit the original size are shortened (see `translations/abbreviations.tsv`) or left in English. No game files are included in this repository. Contributions welcome, see [CONTRIBUTING.md](CONTRIBUTING.md).
