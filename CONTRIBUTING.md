# Как помочь с переводом

Спасибо! Править перевод можно без программирования: достаточно текстового редактора и самой игры.

## Что нужно

- Своя копия игры (клиент Revival) и Python 3.8+.
- Склонированный или скачанный репозиторий.

## Где что лежит

`translations/ru/<таблица>.tsv`: по строке на перевод, `ключ<TAB>текст`. В тексте перенос строки записывается как `\n`, табуляция как `\t`, обратная косая как `\`.

Английский оригинал в репозитории **не хранится** (это игровой текст). Чтобы видеть его рядом с переводом, выгрузите таблицы из своей игры:

```bash
python tools/twa_ru.py sheet --game "D:\Total War Arena" --out sheets
```

В папке `sheets` появятся CSV (разделитель `;`): ключ, английский, русский, длины. Эту папку **не коммитьте** (она в `.gitignore`).

## Правила

1. **Разметку не менять.** Всё в `[[col:...]]...[[/col]]`, `[[img:...]]`, `{...}`, `%d`, `%S`, `<...>`, `||` и переносы строк должно остаться в том же количестве. Скрипт отбрасывает перевод, у которого разметка не совпала (команда `report` покажет такие строки с причиной «разметка»).
2. **Длина важна.** Клиент падает, если размер файла внутри пака меняется. Перевод длиннее оригинала вытесняет другие строки из того же файла. Чем короче, тем больше строк влезет. Проверяйте командой `report` (см. ниже).
3. **Единая терминология.** Ориентируйтесь на уже переведённое: *агрессия, защита, мораль, мобильность, рывок, удар рывком, отражение рывка, фаланга, строй, ранг (tier), опыт отряда, свободный опыт, расходники*. Новые термины добавляйте, согласовав в Issues.
4. **Не оставляйте служебные слова.** Строки вроде `placeholder`, `test`, `Not in use` переводить не нужно.
5. Кодировка файлов: UTF-8, переводы строк `\n`, без BOM.

## Проверка

```bash
python tools/twa_ru.py apply --game "D:\Total War Arena" --dry-run --csv report.csv
```

`--dry-run` ничего не пишет. В `report.csv` видно, какие строки не влезли (`не влезло`) или отброшены из-за разметки (`разметка`). Затем примените перевод без `--dry-run` и посмотрите в игре.

## Сокращения

Если строка не влезает, скрипт сам пробует словарь [`translations/abbreviations.tsv`](translations/abbreviations.tsv): `этап<TAB>что<TAB>на что`. Этап 1 — безобидные синонимы (*Увеличивает → Повышает*), этап 2 — сокращения слов (*в ближнем бою → в ближ. бою*). Добавляйте полезные правила, но следите, чтобы сокращение было понятным и не ломало другие строки (правило применяется ко всем строкам, которым не хватило места).

## Pull request

1. Форкните репозиторий, правьте `translations/ru/*.tsv`.
2. Проверьте `--dry-run` (нет новых «разметка»).
3. В описании PR укажите, какие таблицы и что улучшено, по возможности приложите скриншот из игры.

## Что нужнее всего

- Длинные тексты: `unit_description_short_texts`, `random_localisation_strings`, описания карт и полководцев (`battles`, `arena_commanders`), обучающие подсказки (`advice_levels`).
- Вычитка уже переведённого: падежи, согласование, единообразие, неудачные сокращения.
- Поиск причины, по которой клиент проверяет размеры файлов в паках. Если найдёте, перевод больше не придётся сокращать.
